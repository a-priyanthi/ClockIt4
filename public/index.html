CS23304 Java Programming Syllabus Architecture

Unit I: Introduction to Java & Date/Time API OOP encapsulation (Student, Subject), Constructors, and java.time API (LocalDate, LocalDateTime). IMPLEMENTED
Unit II: Polymorphism, Inheritance & Interfaces Identifiable, Schedulable interfaces; BaseEntity, AcademicItem abstract classes; Method overloading and overriding. IMPLEMENTED
Unit III: Exception Handling & Multithreading Custom exceptions (AcademicClockException, ResourceNotFoundException) + BackgroundScheduler daemon thread with synchronization locks. IMPLEMENTED
Unit IV: Collections, Streams API & JDBC Database Generic CrudRepository<T, ID>, Java Streams pipelines for averages and sorting, and embedded H2 SQL database via standard JDBC. IMPLEMENTED
Unit V: Web Development & REST Framework Multi-threaded HTTP Server handling REST endpoints (/api/auth/*, /api/overview, /api/attendance, etc.) and serving responsive web assets. IMPLEMENTED
